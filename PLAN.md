## Versioned endpoints
Version the endpoints so that in the future we have a way to maintain backwards compatibility when
we want to make breaking changes to the API structure.

## Surviving configuration changes
Ensure that screens properly survive configuration changes; especially that no user input is lost
during a configuration change. And no unnecessary network requests are made during a configuration change.

Start a server locally or remotely and test against it.
